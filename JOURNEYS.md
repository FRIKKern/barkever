# Journeys

A journey is a stable acceptance requirement, not a status. Every branch and Trail names one. Status lives in Barkpark.

```
capture ─► browse ─► find ─► organize ─► link ─► plan
   J01       J02      J03       J04       J05     J06
                 ask ─► AI edit        Mac app ─► offline
                 J07      J08            J09        J10
```

| ID | Journey | Passes when |
|---|---|---|
| J01 | Capture | Cmd-N gives a cursor in under 1 s. A keystroke reaches the screen in under 16 ms and never waits on the network |
| J02 | Browse | Sidebar → notebook → list → note. Every step is in the URL; Back works |
| J03 | Find | Search finds notes by words in title or body; first results in under 150 ms from the local replica |
| J04 | Organize | Notebooks, tags, shortcuts and recent notes, each one click from the sidebar |
| J05 | Link | Link a note to another; the target shows the backlink |
| J06 | Plan | Checklist items become tasks on a board; each links back to its line |
| J07 | Ask | ✨ answers from my notes, cites every note used, says "not in your notes" when true, never edits |
| J08 | AI Edit | Select → AI Edit → visual diff → accept or reject each change → one-step undo |
| J09 | Mac app | Same app on a clean Mac account; AI uses my Claude or ChatGPT login |
| J10 | Offline | An hour offline: create, edit, delete. Reconnect: all synced in under 10 s. A conflict keeps both versions side by side |
