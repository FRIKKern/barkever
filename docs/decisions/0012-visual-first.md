# 0012 Visual first, everywhere

Accepted 2026-10-28.

**Decision.** Docs, Papers, Trails, task closes and the app itself lead with a picture: a diagram, a table, a screenshot, a preview or a visual diff. Words explain the picture and stop. `npm run check` enforces size caps and a picture near the top of README and docs.

**Why.** Barkever is for visual thinkers. Human time is the scarcest thing we spend.

**Instead of.** Prose-first docs with images as an afterthought.
