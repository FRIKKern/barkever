# 0004 Editor: bp-paper-canvas

Accepted 2026-10-28.

**Decision.** Notes are edited in Barkpark's `<bp-paper-canvas>` (PortableDoc). We never build our own editor.

**Why.** Studio decision 0004 and Barkdown both host it. Fixes land in Barkpark once and every app gets them.

**Instead of.** Tiptap, Lexical or a custom ProseMirror build.
