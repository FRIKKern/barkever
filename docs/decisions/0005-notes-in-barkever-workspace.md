# 0005 Notes: own types in a barkever workspace

Accepted 2026-10-28.

**Decision.** `note` and `notebook` are Barkever's own document types with a PortableDoc body, in a `barkever` workspace on guerrilla.barkpark.cloud. A note can be shared as a Paper later.

**Why.** Papers carry a publish wall (tags, descriptions) that is too heavy for a quick note. A separate workspace keeps app data off the dev board.

**Instead of.** Storing notes as Papers; sharing the default workspace.
