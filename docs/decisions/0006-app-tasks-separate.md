# 0006 App tasks stay out of the dev board

Accepted 2026-10-28.

**Decision.** Tasks created inside Barkever live in the barkever dataset. Work on Barkever itself is tracked with `bp` on the guerrilla board.

**Why.** Barkpark ruled on 2026-10-09 that app tasks must not land on the bp board, its GitHub mirror or its crons.

**Instead of.** One shared task list for product and development.
