# 0009 Curated pictures in git, run evidence outside

Accepted 2026-10-28.

**Decision.** Curated reference images live in `reference/` and `docs/img/`: webp or svg, each under 300 KB, under 5 MB in total. Screenshots and recordings from runs go in the Trail or the Barkpark task.

**Why.** Barkever is for visual thinkers, so docs need pictures. Barkdown's repo grew to 2 GB from committed run screenshots.

**Instead of.** No images at all; committing every run's screenshots.
